# NASA data research

Candidate resources, **not a confirmed list of official challenge datasets**:

| Resource | URL | Potential use |
| --- | --- | --- |
| NASA PDS | https://pds.nasa.gov/ | Planetary science archive |
| PDS Orbital Data Explorer | https://ode.rsl.wustl.edu/mars/ | Mars orbital datasets |
| Mars Trek | https://trek.nasa.gov/mars/ | Terrain and planetary mapping |
| HiRISE | https://www.uahirise.org/ | High-resolution imagery |
| Space Apps | https://www.spaceappschallenge.org/ | Official challenge details |

For each dataset, record mission, instrument, geographic coverage, resolution, projection, coordinate convention, units, attribution and limitations.

Avoid presenting static data as live weather or simulation outputs as validated astronaut safety predictions.
