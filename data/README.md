# Local planetary data

`raw/` and `processed/` are ignored local storage directories. Create them with `mkdir -p data/raw data/processed` after cloning; do not commit datasets. No data is downloaded during initialization.

Before ingestion, record source URL, mission/instrument, retrieval date, checksum, licensing/attribution, coverage, resolution, projection, coordinate conventions, units, nodata values and processing steps. See `docs/DATA_SOURCES.md`.
